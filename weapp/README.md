# 小淼饭店 · 微信小程序（云开发版）

把演示版 H5 点餐站迁移到微信小程序 + 云开发的工程。业务逻辑、页面结构与原演示版一一对应，数据层从 `localStorage` 换成云数据库。

## 目录结构
```
weapp/
├── app.js                  # 入口：初始化云开发 + 获取 openid
├── app.json                # 页面注册 + tabBar（点餐/订单/后台）
├── app.wxss                # 全局样式
├── project.config.json     # 工程配置（AppID 占位符需替换）
├── sitemap.json
├── utils/
│   ├── seed.js             # 种子数据（店铺/商品/规格/优惠券）
│   ├── format.js           # 金额/时间格式化
│   ├── store.js            # ★ 云开发数据层（核心）
│   └── cart.js             # 跨页面共享购物车
├── pages/
│   ├── customer/           # 顾客点餐（banner/分类/商品/购物车/下单）
│   ├── order/              # 我的订单（状态 + 已完成才可评价）
│   ├── admin/              # 商家后台（订单推进/商品上下架/店铺设置）
│   └── product/            # 商品详情
└── cloudfunctions/
    └── login/              # 返回 openid（「我的订单」按用户隔离）
```

## 数据模型（云数据库）
- 集合 `store`，文档 `_id = main`：整份店铺数据（shop / settings / products / specs / coupons）。`doc.watch()` 实现菜单/设置的实时同步。
- 集合 `orders`：每笔订单一个文档（独立集合，避免「顾客下单」与「商家改状态」并发写互相覆盖）。`collection.watch()` 实现订单实时推送。

> 与原演示版差异：演示版把订单也塞进同一个 `data.json`，多设备并发会互相覆盖；小程序版把订单拆成独立集合，是上线必须做的一步。

## 上线步骤（按顺序）

### 1. 注册小程序，拿到 AppID
- 微信公众平台 mp.weixin.qq.com → 注册小程序（个人主体可先用于开发，无需营业执照）。
- 把 `project.config.json` 的 `appid` 改成你的 AppID（现在填的是 `wxYOUR_APPID_HERE`）。

### 2. 开通云开发，填环境 ID
- 微信开发者工具 → 点「云开发」→ 开通 → 新建环境，拿到 **环境 ID**。
- 把 `app.js` 里 `globalData.env` 的 `YOUR_CLOUD_ENV_ID` 改成你的环境 ID。

### 3. 建数据库集合 + 安全规则
- 云开发控制台 → 数据库 → 新建集合 `store` 和 `orders`。
- 安全规则（`store` 集合示例，开发期可放宽；**上线前务必收紧**）：
```json
{ "read": true, "write": true }
```
> 生产环境建议：小程序端只允许读，写操作走云函数（用 `cloud.callFunction` 服务端鉴权），避免被恶意篡改菜单价格。

### 4. 部署 login 云函数
- 在 `cloudfunctions/login` 目录右键「上传并部署（云端安装依赖）」。
- 它用 `cloud.getWXContext()` 返回调用者 openid。

### 5. 导入并运行
- 微信开发者工具 → 导入项目 → 选择本 `weapp/` 目录 → 编译。
- 首次进入「点餐」页会自动把 `seed.js` 的种子数据写入 `store/main`；之后商家在后台改的一切都会实时同步到顾客端。

## 与原演示版对照
| 能力 | 演示版 | 小程序版 |
|------|--------|----------|
| 载体 | 浏览器 H5 | 微信小程序 |
| 存储 | localStorage 本机 | 云数据库（多端共享、永久） |
| 同步 | 同浏览器 BroadcastChannel | 云 `watch()` 多设备秒级 |
| 支付 | 模拟 | 暂未接（见下） |
| 订单隔离 | 无 | 按 openid「我的订单」 |
| 评价 | 按钮 | 仅「已完成」订单可写 |

## 后续（阻塞在营业执照的部分）
- **微信支付**：必须企业/个体工商户主体 + 微信支付商户号（需营业执照 + 对公/法人结算）。在 `pages/customer` 结算完成后调用 `wx.requestPayment`（建议用云函数 `cloudPay` 免鉴权调用），钱 T+1 结算到银行卡。
- **订阅消息**：商家接单/出餐时推送订阅消息（需小程序后台申请模板 + 用户授权）。
- **小程序备案**：上线前必须在公众平台做 ICP 备案（通常 7–20 天）。
- **桌贴小程序码**：公众平台「小程序码」生成，扫码直达点餐页。
