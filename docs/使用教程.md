## 二、商家后台日常操作（重点）

### 1. 打开后台
点上面的「商家后台」链接 → 左下角能看到同步徽标：
- ☁ 云端已连 → 正常，改商品会自动同步
- ☁ 本机模式 → 没连上，去左下「☁ 云端同步设置」重粘一次令牌

### 2. 添加新商品
后台里找「添加商品 / 新增」按钮 → 填：
- 菜名、价格、分类、图片
- 详情（长描述、原料/份量、类型、做法、保质期、小贴士）—— 这些顾客点进去能看到

### 3. 编辑已有商品
在商品列表点对应菜 → 改价格/详情/上下架 → **保存即生效**，不用重新部署。

### 4. 改完自动同步（核心）
你点保存的瞬间，数据会**实时推送到 GitHub 仓库**（`demo/assets/data.json`）。
顾客端打开页面会**自动拉最新数据**，所以：
- 你加一道菜 → 顾客立刻能看到
- 你改价格 → 顾客立刻看到新价
- 跨设备（手机/电脑）打开后台，数据都一致

> 💡 你改的是「数据」，不需要重新部署网站；只有我改了页面代码（HTML/JS）才需要重新部署。

### 5. 看评价 / 管订单
顾客买后可对商品打 5 星 + 写评语 + 传图（和美团一样）。在后台对应入口可查看。

## 三、顾客怎么点餐

1. 顾客扫桌上二维码（或点开「顾客点餐端」链接）
2. 浏览菜单 → 点商品看详情和评价 → 加入购物车

4. 老板在后台看到订单、出餐

## 四、换手机 / 清缓存怎么办

当前是「手动令牌」模式：令牌只存在你**这一台设备的浏览器**里。
- ✅ 同一台手机/电脑：粘一次就长期有效，日常不用再管
- 🔄 换手机、或清了浏览器缓存：去后台左下「☁ 云端同步设置」把令牌**重粘一次**即可

> 令牌就是 `ghp_` 开头那串（你 GitHub 账号里那把 classic PAT），粘进浏览器、不公开，安全。

## 五、关于「全自动（零粘贴）」模式

你之前选了"全部自动化"，代码我已写好并通过验证（前端代理模式 + Cloudflare Worker 代理），**只差最后一步部署**：
- 需要你提供 **Cloudflare 的 Account ID + API Token**（用来藏令牌的服务器，我没有你的账号凭证无法代部署）
- 部署后，后台改商品**彻底不用粘贴令牌、任何设备自动同步**

**如果你嫌粘一次麻烦、想要真·全自动**，把这两项发我，我立刻部署接通。
**如果你觉得现在这样（一台手机粘一次）就够了**，那现在就能正常用了，不用动。

## 常见问题

**Q：改了商品顾客看不到？**
A：确认后台左下徽标是「☁ 云端已连」。若是「本机模式」，去「☁ 云端同步设置」重粘令牌。顾客端刷新一下页面。

**Q：徽标一直「连接中」？**
A：多半是令牌失效/权限不对（classic PAT 需勾 `repo` 权限），或网络问题。重粘一次试试。
